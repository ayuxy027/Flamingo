AI Native Frontend Testing Toolkit

A browser your agent drives in a loop. One source file, zero dependencies, built on Bun.

The problem

An agent looking at your frontend is effectively blind. Playwright hands it a DOM dump it burns thousands of tokens failing to parse, then leaves it guessing whether its last click did anything at all.

The loop

Observe, act, observe. Every action returns the resulting page state, and every observation reports what changed since the last one — so the agent knows when it is making progress and when to try something else.

observe   → 1 actionable control, 6 blocked behind div#cookiewall
click     → changed: true, 7 controls now reachable
click     → changed: true, "Task complete" appeared
click     → changed: false   ← that action did nothing; try something else

What it finds

Dead controls

Buttons wired to nothing, and buttons swallowed by an overlay — reported separately, because they are different bugs.

Fields that lie

Inputs that take focus but silently discard what you type. Only found by actually typing.

Race conditions

Rapid clicks, reload mid-request, navigate away mid-action. Finds unhandled rejections a single click never will.

Layout breaks

Horizontal overflow across viewports, with the offending elements named.

Broken assets

Images and stylesheets that failed, with HTTP status codes on the chrome backend.

What blocks the page

A cookie wall or modal shows up as one element blocking many controls — so the agent dismisses it first.

Install

npx flamingo init

Writes an MCP server entry and an agent skill into your project, merging rather than overwriting. Then ask your agent to check your app.

$ flamingo crawl http://localhost:3000

  14 controls found, 14 tested
  ✓ 12 responded
  ✗ 2 dead

    ✗ button#checkout "Checkout"  blocked by div.modal-backdrop
    ✗ a.help          "Help"      no handler fired

Zero dependency

Built for Zero Dependency 2026, Track A. The whole project is one TypeScript file using nothing but the Bun standard library — the only imports are node:fs and node:path. Seventeen packages it would otherwise have needed are documented, along with what replaced each.

$ bun run proof

  ✓ dependencies: empty
  ✓ peerDependencies: empty
  ✓ node:fs — standard library
  ✓ node:path — standard library
