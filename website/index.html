The loop

Observe, act, observe.

Every action returns the resulting page state. Every observation reports what changed since the last one — so the agent knows when it is making progress, and when to stop repeating itself.

observe

click
changed: false ← that did nothing; try something else

What it finds

Bugs a click test walks straight past.

Dead controls

Buttons wired to nothing, and buttons swallowed by an overlay — reported separately, because they are different bugs with different fixes.

Fields that lie

Inputs that take focus but silently discard what you type. Only found by actually typing into them.

Race conditions

Rapid clicks, reload mid-request, navigate away mid-action. Finds unhandled rejections a single click never will.

What blocks the page

A cookie wall shows up as one element blocking many controls — so the agent dismisses it instead of concluding the page is broken.

Layout breaks

Horizontal overflow across viewports, with the offending elements named and measured.

Broken assets

Images and stylesheets that failed to load, with HTTP status codes on the Chrome backend.

Zero dependency

The claim is checked, not asserted.

A script parses the manifest, strips comments from the source and resolves every import. The only two are node:fs and node:path. Seventeen packages it would otherwise have needed are documented, along with what replaced each.
